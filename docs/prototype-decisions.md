# 我们的时光：已确认的原型决定

## 当前设置页职责（2026-11-05）

- “我们”页只展示资料，移除重复的首页编辑、日期编辑跳转和封面；资料区只保留“共同空间设置”。
- 共同空间设置保留本人的头像与昵称、空间名称、成员与邀请、切换及离开/删除空间。删除封面、起始日和推荐页文案设置。
- “两个人的称呼”标签改为“空间名称”，只在共同空间设置修改；首页编辑只修改首页一句话与起始日。
- 点餐页“今天吃什么”入口改为“帮我选菜”，保留推荐功能，使用固定文案并移除旧自定义标题缓存。
- 个人资料、空间名称与首页设置分别保存，避免编辑一个区域时覆盖另一区域的旧值；旧日期与图片数据不因移除设置入口被清空。
- 成员页与切换、离开、删除操作统一使用“共同空间”；仅创建者且没有其他成员时可删除。

本页记录用户明确认可或修正过的整合版原型（持续更新）。以后调整页面时，以这些决定和实际原型为基准；演示日期、照片和统计数字不属于真实业务数据。

## 产品与导航

- 整合版名称为「我们的时光」。「我们的小日子」已被否定，不再使用。
- 底部五个入口：**首页、小饭桌、日历、足迹、我们**。小饭桌是生活空间中的一个模块。
- 小饭桌入口直接进入菜单。菜单顶部提供「今天吃什么」「点单与吃过」「收藏菜谱」「菜单管理」等常用入口；进入后应能返回小饭桌。
- 「我们」页是独立页面，不能在总原型中遗漏。它集中展示双方成员、共同日期、日历与足迹入口、共同资料及消息设置。饭桌管理留在小饭桌相关设置中。

## 视觉基准

- 用户认可的整合版画风是**暖纸色、鼠尾草绿、留白、温和的卡片**。当前整合页面的主色参考 `#F7F5EE`、`#FFFEF9`、`#42664F`、`#E7ECDD`，图标与地图的颜色也应跟随这套原型。
- 生活空间首页展示可编辑的两人称呼、单独保存的一句话、在一起天数、下一个百日节点、近期日子及三个模块入口。天数和节点根据共同起始日期计算，不手动填写。
- 「我们」页已补做同主题原型；卡片内的两人称呼、头像和共同日期优先来自真实资料，不能把原型中的示例日期或图片写入线上数据。
- 菜品图片的系统裁剪流程与足迹照片是两套不同规则；此前尝试的菜品自定义裁剪已按用户要求撤回。

## 日历与足迹

- 日历支持在一起日期、每百日及周年节点、公历／农历生日、每年重复的纪念日、指定某一天的倒计时；可新增、编辑、删除。
- 足迹页按原型使用**中国省级地图轮廓**与浅绿配色，标记照片地点，并可在「地图」「照片墙」之间切换。地点由用户选取；不能因没有照片而显示虚构足迹。
- 足迹地图采用无地点文字的照片图钉，缩略图用细线连接地理坐标；点图钉高亮所属省份，点省份筛选当前已加载照片。缩放/拖动和筛选使用柔和短缓动，不依赖在线地图服务。
- 足迹原图保留原始字节、像素尺寸和横竖比例，兼容 4:3、16:9 及其他不规则尺寸；另生成等比例压缩预览以节省加载成本。照片墙和大图查看都应能看到完整照片。
- 网页版足迹相册目前是设计预览。产品方向是小程序随手记录、未来网站大屏回看；网站生产版尚未交付。
