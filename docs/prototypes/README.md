## 已确认并落到小程序代码的取舍

- 分类在主菜单和管理页均使用文字名称，不显示 emoji 图标；分类编辑仅保留名称。
- 六点手柄是唯一拖动入口。编辑、删除与拖动分别占据独立触控区域，避免误触。
- 排序数字属于内部数据，不在分类或菜品编辑界面暴露。
- 二级、三级页面使用返回入口，不重复显示四栏底部导航。
- 头像、菜品照片和订单照片都用现有的真实上传链路；视觉稿照片不作为项目素材使用。

二级、三级页面已经按这组视觉稿改造；分类图标不再显示，也不能在小程序中编辑。旧的 `categories.icon` 和 `starter_categories.icon` 已通过 `007_remove_category_icons.sql` 从现有生产库移除；新库的 `schema.sql` 也不再定义这些列。已有旧库升级前应先核对迁移记录与 API 版本。图片比例、压缩和已有图片的处理方式见 [image-policy.md](../image-policy.md)。

## 生成说明

使用内置 imagegen 的 `ui-mockup` 模式生成，参考了已确认的四栏主页面原型及当前菜单截图。四组提示主题分别为：

1. 菜单管理与分类管理：搜索、下架、文字分类、六点拖动手柄。
2. 分类编辑与菜品编辑：单字段分类弹层、菜品图片及常用信息表单。
3. 菜品详情与点菜单：照片、估算热量、历史次数、数量调整、留言及提交。
4. 点单详情与小饭桌设置：上菜状态、饭后记录、成员与可编辑首页文案。
