# 我们的时光 · 小程序

微信开发者工具直接打开本目录，不依赖后端目录或 npm 运行时。前端采用暖纸色、鼠尾草绿与已确认的五页原型；共享空间包含饭桌、日历和足迹。

- 入口和导航：`app.json`；请求地址：`config/index.js`。
- 数据请求：`services/`；纯日期、地图投影、上传签名及购物车辅助：`utils/`。
- 日历记录与重要日子分开新增；原图完整保存，批量照片同一批共用地点日期。
- 只声明 `chooseLocation` 地点选择，不使用 `getLocation`。公众平台还需在隐私指引声明“选择的位置信息”。
- 新的数据库表名由后端适配，前端继续使用既有 API URL 和兼容字段；不要把空间 ID 作为可信权限凭证。
- AppSecret、数据库密码、COS 永久密钥及真实模板 ID 不写进前端代码或 Git。

根目录 `npm test` 检查前端行为，`npm run format` 统一 JS/WXSS 格式。正式上传前需双方真机验收；预览不等于正式发布。
